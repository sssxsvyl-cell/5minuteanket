# 🎵 Müzik dosyası

Şarkını bu klasöre koy ve adını **`song.mp3`** yap.

Ağaç şöyle görünmeli:

```
public/
└── music/
    └── song.mp3   ← şarkı buraya
```

Site çalıştığında şarkı `/music/song.mp3` yolundan otomatik oynatılır.
Tarayıcı otomatik oynatmayı engellerse, kullanıcı sayfada herhangi bir
yere dokunduğu anda müzik başlar.

GitHub'a yüklerken `public/music/` klasörünün içine `song.mp3`
dosyasını eklemen yeterli.
